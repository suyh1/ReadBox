# EPUB 与多看适配约定

阅读模块预留在此目录。共享前端使用 epub.js 处理 EPUB 书脊、章节装载、分页和定位；多看适配层使用章节渲染钩子，处理针对多看阅读 App 编写的 XHTML、CSS 和脚注约定。此阶段锁定依赖与宿主边界，后续实现由同一份样书驱动。

| 样书内容 | 四端验收行为 |
| --- | --- |
| 标准 EPUB 2 / EPUB 3 小说 | 保留目录顺序、段落结构和章节跳转 |
| 多看脚注与回链 | 桌面点击或手机轻触可展开，关闭后保留原阅读位置 |
| 自带字体、章标题、插图 | 字体和图片来自书内资源，标题、缩进与图注对照多看参考页 |
| 分页与样式降级 | 在固定字号和视口记录段落顺序、分页与溢出；未识别的扩展保留可读内容 |

在用户授权的样书上记录多看 App 参考截图、字号、视口和版本，用同一章节分别验证桌面 Chromium 与手机 Gecko。阅读正文与应用设置隔离，导入的书籍内容无权调用宿主接口。多看兼容目标是排版和交互行为；本工程采用自带引擎分发。
