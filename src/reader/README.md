# 阅读体验与 EPUB 适配

## 调研与实现取舍

以各产品公开的用户指南与功能说明为依据。这些资料能说明交互和功能，实际任务用时、触达便利性与排版质量仍需要在 ReadBox 上测量。

| 阅读器 | 借鉴的体验 | ReadBox 的落点 |
| --- | --- | --- |
| [Apple 图书](https://support.apple.com/guide/iphone/read-books-iphc1af7c57/ios) | 阅读时收起控件，按需要调出导航或外观设置 | 正文轻点切换专注模式。手机底部翻页、目录和书摘均单手可达 |
| [Readwise Reader](https://readwise.io/read) | 阅读中直接摘录，之后集中回顾 | 选中文字即出现划线与笔记操作；每条书摘都可回到原段落 |
| [Readest](https://readest.com/) | 主题与排版个性化、批注和朗读共用同一个阅读视图 | 主题、字号、行距、版心和阅读模式在书内调整并记住，可调用系统离线语音 |
| [Thorium](https://thorium.edrlab.org/en/) | 首要阅读操作兼顾键盘和触屏 | 键盘翻页、查找快捷键、具名按钮、可用 Esc 关闭的工具面板 |
| [KOReader](https://koreader.rocks/user_guide/) | 保留出版样式并允许覆盖，阅读笔记可带走 | 默认保留书内字体和行距，支持 Markdown 书摘 |
| [calibre](https://manual.calibre-ebook.com/viewer.html) | 书内检索、书签与位置恢复 | 导入单本直接打开，书房一键续读，跨章搜索后可返回跳转前的位置 |

当前优先级是打开一本书、舒适阅读、留下想法和下次接着读。跨设备续读可通过 WebDAV 同步每本书的 CFI。双书对照和跨库回顾属于后续候选。

## 数据与渲染

- IndexedDB 分开保存书架记录与 EPUB 原文。导入以文件内容的 SHA-256 去重，修改书签、笔记和阅读进度时使用读写事务。移除书籍时同时清理两个存储区。
- epub.js 装载书脊、出版样式、插图与字体。定位和书摘保存为 EPUB CFI。书架百分比按书脊位置和当前章节页数估算，改变字号不会改写书摘锚点。
- 章节在禁用脚本的沙箱 iframe 中渲染。章节内容策略只允许书内替换得到的资源；脚注以文本呈现。搜索逐章读取独立文档，每次最多显示 200 条，可匹配跨行内标签的文字。
- 支持 EPUB 3 的 noteref、doc-noteref 以及多看 duokan-footnote。按引用章节解析相对路径和片段，同章或跨章脚注可原地展开。普通书内链接跳转后可返回。[多看脚注约定](https://github.com/Aeroblast/EpubFootnoteAdapter)

## 验收

内置《书页之间》为项目原创 EPUB 3，含三个章节、目录与脚注。桌面安装包冒烟检查使用临时书架验证开书、脚注、跨章检索、批注、续读及显示设置。

还需在用户授权的多看精排样书上，对照多看 App 的版本、字号、视口逐章核对内嵌字体、图注、竖排与分页。小米真机的系统文档选择器、返回手势、原生语音与银河麒麟 ARM64 软件绘制性能需要单独验收。
